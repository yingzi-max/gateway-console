远控设备对照

按「同 IP + 时间窗」把远控上线的设备绑到订单上：访客用自己手机访问前台、装包上线，IP 一般不变。

客户端分流跳转

访客打开站点入口页时，按设备类型直接跳转到对应 URL，爬虫单独处理。这是全站优先级最高的跳转配置。

每类客户端可单独填写跳转 URL 与点击上限；留空表示该类客户端进入时不分流，点击时回落到模板跳转链接。未知客户端同时作为手机端未精确匹配时的兜底。

测试按钮

粘贴任意 User-Agent，查看会被识别成什么客户端、并跳到哪个 URL。

人机验证

在所有前台页面之前插入验证页，未通过验证无法访问任何页面。

验证页样式会自动跟随当前域名的模板配色（国税e-Tax 与 Vpass 为绿色系，其他模板为墨绿色系），互不影响。

爬虫专用跳转

识别到爬虫/自动化客户端时，导向独立页面，避免把真实链接暴露给采集程序。

访问频率封锁

同一来访者「打开进入网站」的次数在单位时间内超过上限时（站内跳转操作不计入），直接拉入黑名单（在「黑名单中心」可管理），后续访问直接拦截跳转，跳过一切检测。
