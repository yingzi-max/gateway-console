安全性とセキュリティ

Mastercardのご利用は、不正使用から保護されています。

定期チェックをお願いします

Mastercard会員様は、定期的にアカウントや取引明細書をチェックし、身に覚えのない取引が記録されていないか確認するようにしてください。不正使用があった場合、ただちにカード発行会社までお知らせください。

ゼロライアビリティー

日本で発行されたMastercardをお持ちの会員様は、不正使用の請求に対して、こちらに記載されている条件をすべて満たしている場合、不正使用から生じるカード保有者の支払い責任をゼロとするルール（ゼロライアビリティー）の対象となります。

ご一報ください

電話やメールを通じて、誰かから個人情報やアカウントデータを尋ねられても教えないでください。そうしたことに遭遇されたら、電話を切り（電子メールの場合にはそのメールを削除し）、カード裏面に記載された電話番号または公式ウェブサイトから発行会社までご一報ください。

Mastercard ID Check™

Mastercard ID Check™ で、安心で安全にお買い物。 オンライン加盟店で、クレジットまたはデビットMastercardでお支払いいただく場合、Mastercard ID Check は、Mastercardのカード発行会社にあらかじめ登録したパスワード、SMSワンタイム・パスワード、生体認証等の技術を活用し、会員の本人認証を行うことで、第三者によるカードの不正使用を防止します。
